**(a)** What is a **kernel**, in plain language? (One or two sentences. No textbook definition copied in; explain it as you understand it.)

**Answer:**
kernel is the part of the operating system that interact with the sw applications and manages the resource needs of each application with the underlying computer harwdare resources (CPU, Memory, Disk, etc).

---

**(b)** A classmate says:

> "I installed WSL, so now I have two completely separate operating systems, Windows and Linux, running side by side, each totally independent."

Is this accurate? Briefly explain why or why not.

**Answer:**
No true. WSL runs as a virtual instance within Windows Operating System. It still depends on Windows to coordinate hardware resources.

---

**(c)** Explain the difference between a **terminal (emulator)** and a **shell**, and give one example of each.

**Answer:**
Terminal is the user interface for taking input, example Windows Terminal. Shell is the processing and execution of the command to provide the output, example PowerShell on Windows.
