**(c)** The SCTP course assumes a POSIX shell (bash or zsh). In your course material, you may encounter commands like these:

```bash
touch notes.txt
export API_KEY=abc123
chmod +x setup.sh
source venv/bin/activate
```

Give **one concrete reason** why running commands like these on Windows PowerShell can fail, even though some commands look similar to PowerShell at first glance. A general-knowledge answer is fine; you do not need to have used PowerShell yourself.

**Answer:**
Running commands like these on Windows PowerShell will fail because PowerShell does not share the same built-in commands or environment syntax as a POSIX shell (like bash or zsh).
While some basic file commands work similarly due to built-in aliases, the critical failure points are:
Incompatible Environment Variables: The export command does not exist in PowerShell. To set an environment variable, PowerShell requires entirely different syntax (e.g., $env:API_KEY="abc123").
Missing POSIX Programs: Commands like chmod (to change file permissions) and source (to execute a script in the current shell) are native Linux/macOS utilities that simply do not exist in Windows.
Different Script Formats: The venv/bin/activate script is a bash script. PowerShell cannot read it and requires you to run the Windows-specific version instead (venv\Scripts\Activate.ps1).
